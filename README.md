# 📊 Data Engineering Project: End-to-End Data Pipeline

An end-to-end data engineering project that demonstrates how to download a dataset from Kaggle, clean and transform the data using Python and Pandas, load it into Oracle Database, and perform data analysis using Oracle SQL.

## 🔄 Project Workflow

## 🚀 Project Overview

This project follows a practical data engineering workflow, transforming raw datasets into structured, analysis-ready data.

### 1. Dataset Acquisition — Kaggle API
- Download datasets programmatically from Kaggle.
- Store the raw dataset locally for processing.

### 2. Data Cleaning and Processing — Python
- Handle missing and inconsistent values.
- Identify and remove duplicate records where appropriate.
- Prepare raw data for further processing.

### 3. Data Transformation and Loading — Python & Pandas
- Load datasets into Pandas DataFrames.
- Transform and validate the data.
- Load the processed data into Oracle Database.

### 4. Data Analysis — Oracle SQL
- Query structured data using Oracle SQL.
- Aggregate and filter data to identify trends.
- Generate insights using SQL queries.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Data processing and pipeline development |
| Kaggle API | Dataset acquisition |
| Pandas | Data cleaning and transformation |
| Oracle Database | Data storage |
| Oracle SQL | Data analysis and reporting |


## ⚙️ Installation and Setup

### Prerequisites
- Python installed
- Oracle Database access
- Kaggle account and API credentials
- Required Python libraries

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd data-engineering-project
```

### 2. Install Dependencies

```bash
pip install pandas kaggle oracledb
```

### 3. Configure Kaggle API

Generate your Kaggle API credentials from your Kaggle account and configure them according to the official Kaggle API instructions.

Keep your API credentials private. Do not commit credentials or passwords to GitHub.

### 4. Configure Oracle Database

Configure your Oracle database connection securely using environment variables or another suitable secrets-management method.

### 5. Run the Pipeline

Execute the Python scripts in the appropriate order:

1. Download the dataset.
2. Clean and transform the data.
3. Load the processed data into Oracle Database.
4. Execute SQL scripts for analysis.
